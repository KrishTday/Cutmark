## Technical contracts

- Timeline, waveform, caption editor and source transport use source seconds. Trim is start-inclusive and end-exclusive. Selected subtitles map through the shared source-to-output range conversion.
- Thumbnails use decoded presentation timestamps, not labels fabricated from slot centers. Frame stepping/out inspection still uses decoded frame timestamps.
- Waveform peaks are amplitude envelopes, normalized to the source maximum for visual readability; they are not calibrated loudness meters. Base bins are approximately 5 ms until the 262,144-bin cap requires coarser aggregation on longer media. Packet memory is bounded independently.
- Timeline seeks retain the latest request while the native element is already seeking. Switching media cancels pending seeks and analysis. Preview speed/volume/context/follow controls do not alter export decisions.
- Caption edits, review notes and readability guidance are saved in project metadata. Existing projects without guidance use sensible defaults. Undo history remains session-local. An operation is one named edit; text typing remains coalesced.
- Scene scans sample at most 480 positions, including the last included source frame. The record identifies source, requested area, settings, detector version, time, planned/checked samples, spacing, actual partial coverage and refinement count. Quick/refined time budgets are 30/120 seconds, with a 150-second worker-response limit. Completing sampling does not imply every intervening frame was checked; refinement completion/limits remain separately visible.
- Unreviewed scene candidates are refreshed only in the checked area. Manual/confirmed cuts and dismissed brackets survive ordinary rescans, while outside cuts always remain. Explicit replacement clears reviewed cuts and wholly covered dismissals in the checked area. Moved detected cuts retain a dismissal of their original bracket. These decisions are named undo actions and stored without rewriting media assets.
- Editorial markers are independent source annotations. Their text, colors and positions persist through trim/export/rescans, and never alter output pixels.
- At the completion of this phase, caption delivery remained separate SRT/VTT files. Styling and actual burn-in are now implemented in the [Phase 3 caption-delivery step](phase-3.md).
